# Sales Performance Analysis

## Business Problem
Businesses need clear visibility on sales performance to understand:

- Revenue growth or decline
- Top-performing products and regions
- Cost impact on profitability

This project analyzes year-over-year sales performance to support strategic decisions.

## Business Context & Data

The dataset simulates transactional sales for 2023–2024, including revenue, cost, profit, quantity, product, and date fields. Each row represents a sales record for a specific product in a specific month.

## Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Excel formulas (SUMIFS, IF, Percentage Change)
- Data validation & formatting


## Data Cleaning
Issues addressed:
-  Inconsistent numeric formats
-  Missing revenue or cost values
-  Unstructured dates

Cleaning steps:
-  Standardized revenue, cost, and profit fields
-  Handled missing/zero values
-  Extracted Year and Month fields for analysis

## Data Transformation
To prepare the data for analysis, additional features were created:

- Added metrics for:
- Year-over-Year (YoY) growth
- Profit margin
- Monthly & yearly summaries
- KPI tables for revenue, cost, profit, and quantity

## Analytical Approach

The Analysis followed a structured approach:

1. Clean raw sales data
2. Create KPIs for performance tracking
3. Compare 2023 vs 2024 metrics using PivotTables
4. Identify growth trends and seasonal patterns
5. Build an executive-style dashboard

## Analysis & Dashboard

Pivot tables and charts show:
- Revenue, cost, profit, quantity sold
- YoY performance trends
- Monthly revenue and profit patterns
- Cost vs revenue distribution
- Top-performing products/regions

## Key Insights & Recommendations
- Revenue increased YoY but profit growth uneven
    - Recommendation: Review low-margin periods
- Seasonal peaks identified
    - Recommendation: Align promotions & inventory
- Profit margins fluctuate despite stable sales
    - Recommendation: Adjust pricing or reduce costs


## Project Structure

- Raw_Data – original dataset
- Pivot_Tables – analytical summaries
- Dashboard – visual performance overview
- Insights – findings & recommendations
